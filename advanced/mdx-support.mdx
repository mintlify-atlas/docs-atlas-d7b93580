## Overview

RyunixJS provides first-class MDX support with optimized component rendering, context-based customization, and server-side rendering compatibility.

## Built-in MDX Components

RyunixJS includes default components for all MDX elements:

```javascript
// Source: packages/core/src/lib/components.js:127-163
const defaultComponents = {
  // Headings
  h1, h2, h3, h4, h5, h6,
  
  // Text
  p, a, strong, em, code,
  
  // Lists
  ul, ol, li,
  
  // Blocks
  blockquote, pre, hr,
  
  // Tables
  table, thead, tbody, tr, th, td,
  
  // Media
  img
}
```

All components are optimized for Ryunix's reconciliation engine.

## MDXProvider

Provide custom components throughout your MDX content tree:

```jsx
import { MDXProvider } from 'ryunix';

function App() {
  const components = {
    h1: (props) => <h1 className="text-4xl font-bold" {...props} />,
    p: (props) => <p className="my-4 text-gray-700" {...props} />,
    code: (props) => <code className="bg-gray-100 px-2 py-1" {...props} />,
  };
  
  return (
    <MDXProvider value={components}>
      <Article />
    </MDXProvider>
  );
}
```

## useMDXComponents Hook

Access MDX components from context within your custom components:

```jsx
import { useMDXComponents } from 'ryunix';

function CustomCode({ children, className }) {
  const components = useMDXComponents();
  const language = className?.replace('language-', '');
  
  return (
    <div className="code-block">
      <div className="code-header">{language}</div>
      <components.pre>
        <components.code className={className}>
          {children}
        </components.code>
      </components.pre>
    </div>
  );
}
```

## getMDXComponents

Merge context components with additional overrides:

```jsx
import { getMDXComponents } from 'ryunix';

function Article({ additionalComponents }) {
  const components = getMDXComponents(additionalComponents);
  
  // components contains both context and additional components
  return <Content components={components} />;
}
```

### API Signature

```javascript
const getMDXComponents = (components) => Object
```

**Parameters:**
- `components` (Object) - Additional components to merge

**Returns:**
- Merged object with context components and provided components

**Source:** `/home/daytona/workspace/source/packages/core/src/lib/components.js:116-122`

**Implementation:**

```javascript
const getMDXComponents = (components) => {
  const contextComponents = useMDXComponents();
  return {
    ...contextComponents,
    ...components,
  };
}
```

### Interactive Code Blocks

```jsx
import { useStore } from 'ryunix';

function CodeBlock({ children, className, live }) {
  const [copied, setCopied] = useStore(false);
  
  const handleCopy = () => {
    navigator.clipboard.writeText(children);
    setCopied(true);
    setTimeout(() => setCopied(false), 2000);
  };
  
  return (
    <div className="code-block">
      <button 
        onClick={handleCopy}
        className="copy-button"
      >
        {copied ? 'Copied!' : 'Copy'}
      </button>
      <pre className={className}>
        <code>{children}</code>
      </pre>
    </div>
  );
}

const components = {
  code: CodeBlock,
};
```

### Custom Links

Add icons or analytics to links:

```jsx
function CustomLink({ href, children, ...props }) {
  const isExternal = href.startsWith('http');
  
  const handleClick = () => {
    if (isExternal) {
      analytics.track('External Link Clicked', { href });
    }
  };
  
  return (
    <a 
      href={href}
      onClick={handleClick}
      target={isExternal ? '_blank' : undefined}
      rel={isExternal ? 'noopener noreferrer' : undefined}
      {...props}
    >
      {children}
      {isExternal && <ExternalIcon />}
    </a>
  );
}

const components = {
  a: CustomLink,
};
```

## Nested MDXProviders

Providers can be nested for granular control:

```jsx
import { MDXProvider } from 'ryunix';

function App() {
  const globalComponents = {
    h1: GlobalH1,
    p: GlobalP,
  };
  
  const articleComponents = {
    code: ArticleCode,
    pre: ArticlePre,
  };
  
  return (
    <MDXProvider value={globalComponents}>
      <Layout>
        <MDXProvider value={articleComponents}>
          <Article />
        </MDXProvider>
      </Layout>
    </MDXProvider>
  );
}
```

Inner providers merge with outer providers (inner takes precedence).

## Server-Side Rendering

MDX components work seamlessly with SSR:

```jsx
import { renderToString, MDXProvider } from 'ryunix';

const components = {
  h1: CustomH1,
  code: CustomCode,
};

const html = renderToString(
  <MDXProvider value={components}>
    <MDXContent />
  </MDXProvider>
);
```

All component customizations are preserved during server rendering.

## Advanced Patterns

### Dynamic Component Resolution

```jsx
import { getMDXComponents } from 'ryunix';

function DynamicMDX({ theme, children }) {
  const baseComponents = getMDXComponents();
  
  const themedComponents = {
    ...baseComponents,
    h1: theme === 'dark' ? DarkH1 : LightH1,
    p: theme === 'dark' ? DarkP : LightP,
  };
  
  return (
    <MDXProvider value={themedComponents}>
      {children}
    </MDXProvider>
  );
}
```

### Component Analytics

Track MDX component usage:

```jsx
function withAnalytics(Component, name) {
  return (props) => {
    useEffect(() => {
      analytics.track('MDX Component Rendered', { name });
    }, []);
    
    return <Component {...props} />;
  };

const components = {
  code: withAnalytics(CodeBlock, 'CodeBlock'),
  img: withAnalytics(Image, 'Image'),
};
```

## Best Practices

### 1. Keep Components Pure

MDX components render frequently; keep them pure:

```jsx
// Good: Pure component
const H1 = (props) => <h1 className="title" {...props} />;

// Avoid: Side effects
const H1 = (props) => {
  console.log('Rendering'); // Don't do this
  return <h1 {...props} />;
};
```

### 2. Spread Props Last

Allow MDX to override your defaults:

```jsx
// Good: MDX can override className
const H1 = (props) => <h1 className="title" {...props} />;

// Bad: className locked
const H1 = (props) => <h1 {...props} className="title" />;
```

### 3. Use Semantic HTML

Maintain accessibility:

```jsx
const components = {
  h1: (props) => <h1 {...props} />,  // Keep semantic tags
  p: (props) => <p {...props} />,
};
```

### 4. Memoize Component Objects

Prevent unnecessary re-renders:

```jsx
import { useMemo } from 'ryunix';

function App() {
  const components = useMemo(() => ({
    h1: CustomH1,
    code: CustomCode,
  }), []);
  
  return (
    <MDXProvider value={components}>
      <Content />
    </MDXProvider>
  );
}
```

## Performance Tips

Ryunix MDX components are optimized by default:

- No wrapper elements (using `createElement` directly)
- Minimal reconciliation overhead
- Compatible with memo and lazy loading

```jsx
import { memo, lazy, Suspense } from 'ryunix';

// Memoize expensive components
const MemoizedCode = memo(CustomCode);

// Lazy load heavy components
const Chart = lazy(() => import('./Chart'));

const components = {
  code: MemoizedCode,
  Chart,
};
```
