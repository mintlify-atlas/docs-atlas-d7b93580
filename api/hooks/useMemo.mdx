## Overview

`useMemo` memoizes the result of an expensive computation, only recalculating when dependencies change. This helps optimize performance by avoiding unnecessary recalculations on every render.

## Signature

```javascript
const memoizedValue = useMemo(compute, deps)
```

## Parameters

<ParamField path="compute" type="Function" required>
  A function that computes and returns the value to memoize. Must be a pure function with no side effects.
  
  Called only when dependencies change or on initial render.
</ParamField>

<ParamField path="deps" type="Array" required>
  Array of dependencies. The memoized value is recalculated only when one of the dependencies changes.
  
  Unlike `useEffect`, the deps array is **required** for `useMemo`.
</ParamField>

## Return Value

Returns the memoized value returned by the `compute` function.

## Usage

### Expensive Calculation

```javascript
import { useMemo, useStore } from 'ryunix'

function fibonacci(n) {
  if (n <= 1) return n
  return fibonacci(n - 1) + fibonacci(n - 2)
}

function FibonacciCalculator() {
  const [num, setNum] = useStore(10)
  const [color, setColor] = useStore('blue')

  // Only recalculates when num changes, not when color changes
  const result = useMemo(() => {
    console.log('Computing fibonacci...')
    return fibonacci(num)
  }, [num])

  return (
    <div style={{ color }}>
      <input
        type="number"
        value={num}
        onChange={e => setNum(parseInt(e.target.value))}
      />
      <p>Fibonacci: {result}</p>
      <button onClick={() => setColor(color === 'blue' ? 'red' : 'blue')}>
        Change Color
      </button>
    </div>
  )
}
```

### Filtering and Sorting Lists

```javascript
function UserList({ users }) {
  const [searchTerm, setSearchTerm] = useStore('')
  const [sortBy, setSortBy] = useStore('name')

  const filteredAndSortedUsers = useMemo(() => {
    return users
      .filter(user => 
        user.name.toLowerCase().includes(searchTerm.toLowerCase())
      )
      .sort((a, b) => a[sortBy].localeCompare(b[sortBy]))
  }, [users, searchTerm, sortBy])

  return (
    <div>
      <input
        placeholder="Search..."
        value={searchTerm}
        onChange={e => setSearchTerm(e.target.value)}
      />
      <select value={sortBy} onChange={e => setSortBy(e.target.value)}>
        <option value="name">Name</option>
        <option value="email">Email</option>
      </select>
      <ul>
        {filteredAndSortedUsers.map(user => (
          <li key={user.id}>{user.name}</li>
        ))}
      </ul>
    </div>
  )
}
```

### Memoizing Object Creation

```javascript
function ComponentWithConfig() {
  const [width, setWidth] = useStore(100)
  const [height, setHeight] = useStore(100)

  // Without useMemo, this creates a new object every render
  // causing child components to re-render unnecessarily
  const config = useMemo(() => ({
    dimensions: { width, height },
    aspectRatio: width / height,
    area: width * height
  }), [width, height])

  return <ChildComponent config={config} />
}
```

### Computing Derived State

```javascript
function ShoppingCart({ items }) {
  const [taxRate, setTaxRate] = useStore(0.08)

  const summary = useMemo(() => {
    const subtotal = items.reduce((sum, item) => sum + item.price * item.qty, 0)
    const tax = subtotal * taxRate
    const total = subtotal + tax

    return { subtotal, tax, total }
  }, [items, taxRate])

  return (
    <div>
      <p>Subtotal: ${summary.subtotal.toFixed(2)}</p>
      <p>Tax: ${summary.tax.toFixed(2)}</p>
      <p>Total: ${summary.total.toFixed(2)}</p>
    </div>
  )
}
```

## Error Handling

Errors in the compute function are caught and logged in development:

```javascript
const value = useMemo(() => {
  if (someCondition) {
    throw new Error('Computation failed')
  }
  return result
}, [deps])

// In development: logs "Error in useMemo computation: ..."
// In production: error propagates normally
```

## Validation

`useMemo` validates its arguments:

```javascript
// ❌ Invalid - compute must be a function
useMemo('not a function', [])

// ❌ Invalid - deps is required and must be an array
useMemo(() => value)
useMemo(() => value, 'not an array')

// ✅ Valid
useMemo(() => value, [])
useMemo(() => value, [dep1, dep2])
```

## Server-Side Rendering

During SSR, `useMemo` always computes the value:

```javascript
if (state.isServerRendering) {
  return compute() // Always compute on server
}
```

## Implementation Details

- Uses `Object.is()` for dependency comparison (same as `useEffect`)
- Stores both the memoized value and dependencies in the fiber
- Recalculates only when dependencies change
- During development, errors are caught and logged

```javascript
const haveDepsChanged = (oldDeps, newDeps) => {
  if (!oldDeps || !newDeps) return true
  if (oldDeps.length !== newDeps.length) return true
  return oldDeps.some((dep, i) => !Object.is(dep, newDeps[i]))
}
```

## When to Use useMemo

**Use `useMemo` when:**
- Computation is expensive (complex calculations, large data transformations)
- You're creating objects/arrays that are passed to child components
- Deriving state from props that rarely change

**Don't use `useMemo` for:**
- Simple calculations (premature optimization)
- Values that change on every render anyway
- Primitives (numbers, strings, booleans) that aren't computed

## Performance Considerations

```javascript
// ❌ Overkill - simple arithmetic doesn't need memoization
const double = useMemo(() => count * 2, [count])

// ✅ Good use case - expensive computation
const primes = useMemo(() => findPrimesUpTo(limit), [limit])

// ✅ Good use case - prevents child re-renders
const style = useMemo(() => ({ color, fontSize }), [color, fontSize])
```

## Best Practices

1. **Include all dependencies** - Don't omit values used in the compute function
2. **Keep compute functions pure** - No side effects or mutations
3. **Don't over-memoize** - Profile first, optimize second
4. **Use for referential equality** - Useful when passing objects/arrays to children
5. **Combine with React.memo** - Memoize both props and component for best results
