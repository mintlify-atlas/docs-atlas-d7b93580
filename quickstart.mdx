## Create Your First App

Get started with RyunixJS by creating a new application using the official create-ryunix-app (CRA) tool.

<Steps>
  <Step title="Create a new project">
    Run the create command with your preferred package manager:
    
    <CodeGroup>
    ```bash npm
    npx @unsetsoft/cra@latest my-ryunix-app
    ```
    
    ```bash yarn
    yarn create @unsetsoft/cra my-ryunix-app
    ```
    
    ```bash pnpm
    pnpm create @unsetsoft/cra my-ryunix-app
    ```
    </CodeGroup>
    
    The CLI will prompt you for configuration options like Tailwind CSS, ESLint, and VS Code settings.
  </Step>

  <Step title="Navigate to your project">
    ```bash
    cd my-ryunix-app
    ```
  </Step>

  <Step title="Start the development server">
    <CodeGroup>
    ```bash npm
    npm run dev
    ```
    
    ```bash yarn
    yarn dev
    ```
    
    ```bash pnpm
    pnpm dev
    ```
    </CodeGroup>
    
    Your app will be running at [http://localhost:3000](http://localhost:3000)
  </Step>

  <Step title="Start building">
    Open `app/index.ryx` in your editor and start building your application!
  </Step>
</Steps>

## Project Structure

Your new RyunixJS project has the following structure:

```
my-ryunix-app/
├── app/
│   ├── index.ryx          # Main page
│   ├── layout.ryx         # Root layout
│   └── errors.ryx         # Error handling
├── assets/
│   └── logo.svg           # Static assets
├── styles/
│   └── global.css         # Global styles
├── public/                # Public static files
├── package.json
└── ryunix.config.js       # RyunixJS configuration
```

## Your First Component

The default `app/index.ryx` file contains a simple counter example:

```jsx app/index.ryx
import { useStore } from '@unsetsoft/ryunixjs'
import logo from '../assets/logo.svg'

export default function Index() {
  const [count, setCount] = useStore(0)

  return (
    <main className="main">
      <img src={logo} alt="Ryunix Logo" className="logo" />
      <h1>Welcome to Ryunix</h1>
      <p className="subtitle">
        A fast, modern, and flexible JavaScript framework for building user interfaces.
      </p>

      <div className="counter">
        <button onClick={() => setCount(count - 1)}>-</button>
        <span>Count: {count}</span>
        <button onClick={() => setCount(count + 1)}>+</button>
      </div>
    </main>
  )
}
```

## Add Interactivity

Let's enhance the component with more interactivity:

```jsx app/index.ryx
import { useStore, useEffect } from '@unsetsoft/ryunixjs'

export default function Index() {
  const [count, setCount] = useStore(0)
  const [message, setMessage] = useStore('')

  useEffect(() => {
    if (count > 10) {
      setMessage('Great job counting!')
    } else if (count < 0) {
      setMessage('Going negative!')
    } else {
      setMessage('')
    }
  }, [count])

  return (
    <main>
      <h1>Interactive Counter</h1>
      
      <div className="counter">
        <button onClick={() => setCount(count - 1)}>Decrement</button>
        <span>Count: {count}</span>
        <button onClick={() => setCount(count + 1)}>Increment</button>
      </div>
      
      {message && <p className="message">{message}</p>}
      
      <button onClick={() => setCount(0)}>Reset</button>
    </main>
  )
}
```

## File-System Routing

RyunixJS uses file-system based routing. Create new pages by adding files to the `app/` directory:

```
app/
├── index.ryx              # → /
├── about.ryx              # → /about
├── blog/
│   ├── index.ryx          # → /blog
│   └── [slug].ryx         # → /blog/:slug
└── api/
    └── hello/
        └── route.js       # → /api/hello
```

### Create an About Page

```jsx app/about.ryx
export const Metatags = {
  title: 'About',
  description: 'About our application'
}

export default function About() {
  return (
    <main>
      <h1>About Us</h1>
      <p>This is a RyunixJS application.</p>
    </main>
  )
}
```

## Adding Layouts

Create shared layouts for consistent page structure:

```jsx app/layout.ryx
import '../styles/global.css'

export const Metatags = {
  title: {
    template: '%s | My App',
    default: 'My App'
  },
  description: 'A modern RyunixJS application',
  viewport: 'width=device-width, initial-scale=1.0'
}

export default function RootLayout({ children }) {
  return (
    <div className="app">
      <nav>
        <a href="/">Home</a>
        <a href="/about">About</a>
      </nav>
      
      <main>{children}</main>
      
      <footer>
        <p>&copy; 2024 My App</p>
      </footer>
    </div>
  )
}
```
