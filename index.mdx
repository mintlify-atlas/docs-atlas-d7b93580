<Note>
  RyunixJS is a modern JavaScript framework that allows you to build static websites and web applications in a similar way to React, Next.js, and Preact, but completely standalone without React dependencies.
</Note>

## Why RyunixJS?

RyunixJS is designed to be more manageable and moldable for each developer while providing powerful features for modern web development.

<CardGroup cols={2}>
  <Card title="Virtual DOM" icon="layer-group" color="#6366f1">

  </Card>
  <Card title="Server-Side Rendering" icon="server" color="#818cf8">
    Built-in SSR and SSG with streaming support for optimal performance
  </Card>
  <Card title="Island Architecture" icon="island-tropical" color="#4f46e5">
    Partial hydration for minimal JavaScript payload and maximum performance
  </Card>
  <Card title="File-System Routing" icon="folder-tree" color="#6366f1">

## Example

Here's a simple counter component to show RyunixJS in action:

```javascript Counter.jsx
import { useStore } from '@unsetsoft/ryunixjs'

function Counter() {
  const [count, setCount] = useStore(0)
  
  return (
    <div>
      <h1>Count: {count}</h1>
      <button onClick={() => setCount(count + 1)}>
        Increment
      </button>
    </div>
  )
}

export default Counter
```
